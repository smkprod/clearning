# clearning — трекер подготовки к AP2 и Junior .NET

Личный трекер обучения: очередь задач с интерливингом, ежедневный код-челлендж,
карточки с интервальным повторением (Leitner), heatmap активности, обратный
отсчёт до IHK Abschlussprüfung Teil 2 (25.11.2026) и чеклист готовности к работе.

Всё хранится локально в `localStorage` — без бэкенда и аккаунтов.

## Ключевая механика

План **не привязан к датам** — это очередь задач. «Сегодня» = следующие
невыполненные задачи из очереди. Пропустил день — очередь просто сдвинулась,
ничего не «сгорело». Задачу можно отложить или переставить.

- **Два потока**: ежедневные мелкие задачи качают навыки, а экран **Проекты** —
  позвоночник: лестница из 7 приложений, которые строишь сам (консоль → REST API →
  БД+auth → тесты → Docker+Azure+CI/CD → фронт → доведение своих pet-проектов).
- **Интерливинг**: день собирается из разных треков (алгоритмы + бэкенд + карточки),
  а не «три недели одного C#».
- **Стрик** выживает в плохой день: достаточно «минимального дня» (по умолчанию 30 мин).
- **Карточки** двигаются по Leitner-боксам 1–5: «снова / трудно / хорошо / легко».
- Программа зашита в `src/data/curriculum.ts` — задачи можно дополнять, прогресс
  пользователя при этом не теряется.

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173
```

## Сборка

```bash
npm run build      # статика в dist/
npm run preview    # локальный просмотр сборки
```

## Деплой на Vercel

Проект — чистая статика Vite, конфигурация не нужна:

1. Запушь репозиторий на GitHub.
2. На [vercel.com](https://vercel.com) → **Add New → Project** → выбери репозиторий.
3. Vercel сам определит Vite (build: `npm run build`, output: `dist`). Жми **Deploy**.

Либо через CLI: `npx vercel` из корня проекта.

> ⚠️ Данные живут в `localStorage` конкретного браузера. Регулярно делай
> **Настройки → Экспорт в JSON** — это твой бэкап при смене устройства.

## Структура

```
src/
  components/   переиспользуемые компоненты (бейджи, прогресс, модалка минут)
  data/         curriculum.ts — вся программа: задачи, карточки, челленджи, майлстоуны
  hooks/        useLocalStorage
  screens/      экраны: Dashboard, Queue, Projects, Flashcards, Activity, Job, Settings
  state/        AppStateContext (состояние + действия), initialState (сид/миграция)
  styles/       глобальные токены тёмной темы
  utils/        даты, Leitner, статистика (стрики, темп к экзамену)
  types.ts      модель данных
```
